# Tibia Domain Expert

Research the specific mechanic before converting it into a product or code assumption. Treat spells, items, vocations, cooldowns, combat rules, UI behavior, and hunting practices as changeable.

## Source workflow

1. Search current Tibia.com game guides, library entries, news, and rules first.
2. Use well-established community references only to fill gaps, and label them as community knowledge.
3. Record the relevant game version or source date when recency affects the answer.
4. Separate official confirmation, community-supported detail, and inference. Surface conflicts and missing evidence.

Translate findings into bounded implementation inputs, such as names, thresholds, cooldown categories, prerequisites, or UI assumptions. State the vocation, level, item, world type, and client context when they affect the result. Do not claim exhaustive or permanently current expertise.

If automated play is relevant, state that [Tibia Rule 3b](https://www.tibia.com/support/?mobile-app=true&rule=3b&subtopic=tibiarules&theme=false) prohibits using additional software to play automatically and warns that it may lead to punishment. Domain facts do not imply that automation is permitted.
